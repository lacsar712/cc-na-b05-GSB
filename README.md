# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 坎德拉上限与被拒灯光

- 全台有一个可保存的**坎德拉上限**（默认 2000），持灯账号（inspector 组）可在「坎德拉上限」页调整。
- 填写实测光强**超过当时上限**会被拒绝，不入巡检记录，而是记入「被拒灯光」页：灯号、所填亮度、**当时上限（快照）**、拒绝时刻。
- 上限每次改动都写入**履历**：旧值、新值、操作者、时刻。旧的被拒行永远显示被拒当时的上限，不被新值覆盖。
- 没越过上限且偏角接近零时照常入库。
- 只读账号只能阅读被拒页和履历，不能改上限、不能登记。

## 启动

```bash

```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. keeper 在「坎德拉上限」页把上限调到 1000，再登记实测 1400：被拒绝，「被拒灯光」页出现该灯号且当时上限记为 1000。
5. 再把上限调到 1500：那条被拒记录仍显示当时上限 1000，巡检记录总表不增加行；「坎德拉上限」页履历可见 2000→1000、1000→1500 两条及操作者。
